# Bundled fonts

Slangdee bundles the unmodified Noto Sans and Noto Sans Thai variable fonts.
Both fonts use the SIL Open Font License, version 1.1.

- [Noto Sans licence](NotoSans-OFL.txt)
- [Noto Sans Thai licence](NotoSansThai-OFL.txt)

Keep each copyright notice and licence with the font when distributing the app.
